# 🌟 منظومة رحلة عبدالله (Abdullah's Journey OS)

منظومة ذكاء اصطناعي فائق لإدارة حياة د. عبدالله الأكاديمية والروحية والمهارية عبر **بوت تليجرام الصوتي** ومحرك **Google AI Studio (Gemini 3.x Multi-Key)** وقاعدة بيانات **Supabase Cloud** مع لوحة تحكم تفاعلية متطورة.

---

## 🚀 المميزات الرئيسية

1. **🩺 المحور الطبي والأكاديمي (الفرقة الرابعة - الفصل الدراسي السابع):**
   - متابعة موديولات الترم السابع وتوزيع الـ 450 درجة:
     - `PED401` — Pediatric 1 (125 درجة)
     - `CAD402` — Cardiac Disorders (125 درجة)
     - `RSD403` — Respiratory Disorders (75 درجة)
     - `HVD404` — Hematological & Vascular Disorders (100 درجة)
     - `SKL 7` — Clinical Skills 7 (25 درجة)
     - `PRF 7` & `ELE 7` (Pass / Fail)
   - توثيق الحالات الإكلينيكية وراوندات المستشفى وتريكات الدكاترة.
   - كويزات ذكية ومحاكي OSCE تفاعلي بالذكاء الاصطناعي.

2. **📖 سجل القرآن الكريم والتثبيت (Spaced Repetition):**
   - تسجيل الحفظ الجديد والمراجعة والورد مع تقييم جودة التثبيت (1-5 نجوم).
   - إعادة جدولة السور ذات التقييم المنخفض تلقائياً.

3. **🕌 الصلوات والعادات اليومية الفائقة:**
   - متابعة الصلوات الخمس في وقتها، قيام الليل، وأذكار الصباح والمساء.
   - تتبع ساعات النوم، الاستيقاظ، التمارين الرياضية، ومستوى الطاقة.

4. **🗣️ مدرب اللغة الإنجليزية الصوتي (Active English Coach):**
   - محادثة صوتية تفاعلية تتحدث فيها بالإنجليزية ويرد عليك البوت صوتياً وتحليلياً.
   - تصحيح الأخطاء القواعدية واستخراج بنك الكلمات المتقدمة (Elevated Vocab).

5. **💵 الخزنة والمصروفات الشخصية:**
   - تسجيل المصروفات والإيرادات اليومية وتتبع أرصدة الخزنة وفودافون كاش وإنستاباي وبنك مصر.

6. **🧠 محرك Gemini Multi-Key المقاوم للتوقف:**
   - تدوير تلقائي بين 3 مفاتيح API و 5 موديلات ذكية (`gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-flash-lite-latest`) لضمان سرعة واستمرارية تامة دون أي توقف.

## ⚙️ خطوات التشغيل

### 1. إعداد قاعدة البيانات (Supabase)
1. افتح لوحة تحكم مشروعك في [Supabase Console](https://supabase.com/dashboard/project/iluvbcadeteawbyrlqmo).
2. ادخل على **SQL Editor** ثم انقر **New Query**.
3. انسخ محتوى الملف `supabase_schema.sql` والصقه واضغط **Run**.

### 2. التشغيل المحلي (Local Polling Development)
لتشغيل البوت محلياً وتجربته فوراً:
```bash
npm run dev
```
افتح تليجرام وابدأ التحدث مع البوت [@abdallahprobot](https://t.me/abdallahprobot)!

### 3. الرفع والاستضافة على Vercel
1. ارفع المشروع إلى مستودع GitHub.
2. اربط المستودع بـ Vercel وأضف متغيرات البيئة من ملف `.env`.
3. لتفعيل الويب هوك، قم بزيارة:
   `https://YOUR_DOMAIN.vercel.app/api/webhook?set_webhook=true`
